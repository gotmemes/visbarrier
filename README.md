# Visbarrier

Toggle barrier block visibility in Minecraft Forge 1.8.9

Now with smoother rendering for better performance on low-end hardware

![Preview](assets/preview.png?raw=true)

## Features

**Keybind Toggle** - Press `B` to show/hide all barrier blocks in your render distance
**Optimized Rendering** - Smoother transition using more selective rendering updates
**Customizable Appearance** - Change textures and models via resource packs

## Usage

**Press `B`** to toggle barrier visibility on/off
*(Change keybind in Options → Controls → Visbarrier)*

You'll see a chat notification confirming the toggle:

| Barriers ON | Barriers OFF |
|-------------|--------------|
| ![Barriers On](assets/chat_notification_on.png) | ![Barriers Off](assets/chat_notification_off.png) |

## Customization

Default uses red translucent blocks with outline for better performance, but can be changed with resource packs

Create resource packs where you can change texture and models:

- **Texture**: `assets/minecraft/textures/blocks/barrier.png`
- **Model**: `assets/minecraft/models/block/barrier.json`

Also, works with Optifine's connected textures
